{panel:title=01  왜 만들었나|titleBGColor=#002f6d|titleColor=#ffffff|borderColor=#002f6d|borderStyle=solid|bgColor=#ffffff}
OpenCode는 오픈소스 AI 코딩 에이전트입니다. 코드를 읽고, 파일을 고치고, 셸 명령을 실행하는 일을 LLM에게 맡길 수 있습니다. 문제는 기본 형태가 CLI와 터미널 UI라는 점입니다.

* 쓰려면 {{opencode}} CLI를 따로 설치해야 합니다.
* 편집기와 터미널 창을 오가며 작업해야 합니다.
* 지금 보고 있는 코드를 에이전트에게 넘기려면 경로를 직접 적어야 합니다.

그래서 엔진을 확장 안에 넣었습니다. VSIX 하나만 설치하면 CLI 설치나 터미널 없이 VS Code 사이드바에서 바로 쓸 수 있습니다.

{panel}

{panel:title=02  화면과 기능|titleBGColor=#002f6d|titleColor=#ffffff|borderColor=#002f6d|borderStyle=solid|bgColor=#ffffff}
왼쪽 사이드바에는 History, Skills, MCP Servers 세 칸이 있고 채팅은 오른쪽 보조 사이드바에 열립니다. {{Ctrl+Esc}}를 누르면 둘 다 열립니다.

||기능||쓰는 방법||
|채팅|응답이 스트리밍으로 나오고, 에이전트가 쓴 도구 활동도 함께 보입니다.|
|대화 기록|History에서 레포지토리별로 묶어 보여 줍니다. 여러 개를 골라 한 번에 지울 수 있습니다.|
|코드 넘기기|선택 영역을 우클릭해 첨부하거나, 입력창에서 {{@}}로 파일을 찾아 붙입니다. 이미지도 붙여넣기나 드래그로 넣을 수 있습니다.|
|명령 실행|{{/}}를 입력하면 OpenCode 명령과 스킬 목록이 뜹니다.|
|모델 선택|에이전트, 모델, 사고 강도(effort)를 고릅니다. 에이전트별로 고른 모델을 워크스페이스마다 기억합니다.|
|질문 응답|에이전트가 선택형 질문을 하면 채팅 상단에 카드로 뜹니다.|
|사용량|입력창 아래에 현재 컨텍스트 토큰과 남은 컨텍스트 창 크기가 표시됩니다.|
|로드 현황|Skills 칸은 엔진이 읽은 스킬을, MCP Servers 칸은 서버별 연결 상태를 보여 줍니다.|

{panel:title=03  내부 구조|titleBGColor=#002f6d|titleColor=#ffffff|borderColor=#002f6d|borderStyle=solid|bgColor=#ffffff}
확장은 세 부분으로 나뉩니다. 화면을 그리는 웹뷰, 엔진과 대화하는 확장 호스트, 그리고 확장 안에 들어 있는 OpenCode 엔진입니다.

{noformat}
 VS Code
 +--------------------------+      postMessage      +------------------------------+
 | Webview (chat UI)        | <-------------------> | Extension host               |
 | webview/main.ts          |                       | extension.ts  chatView.ts    |
 | marked + DOMPurify       |                       | client.ts     server.ts      |
 +--------------------------+                       +--------------+---------------+
                                                                   |
                                                    HTTP API + SSE (/event)
                                                    Basic auth, random password
                                                                   |
                                                    +--------------v---------------+
                                                    | Bundled opencode.exe 1.18.32 |
                                                    | serve on 127.0.0.1:<port>    |
                                                    +--------------+---------------+
                                                                   |
                                                         Model provider APIs
                                                         (from opencode.json)
{noformat}

# 사이드바를 열면 확장 호스트가 빈 포트를 하나 잡고, 동봉된 엔진을 루프백 주소에서 서버 모드로 띄웁니다.
# {{/global/health}}가 응답할 때까지 최대 20초 기다립니다.
# 이후 세션, 메시지, 모델, 권한, 질문은 OpenCode 로컬 HTTP API로 처리합니다. 스트리밍 응답과 상태 변화는 {{/event}} SSE 스트림으로 받습니다.
# 웹뷰는 엔진에 직접 접근하지 않고 확장 호스트와 메시지만 주고받습니다.
# VS Code를 닫으면 엔진 프로세스도 같이 종료됩니다.

||항목||값||
|언어|TypeScript, esbuild 번들|
|코드 규모|src와 webview 합쳐 약 3,500줄|
|테스트|node:test 기반 단위 테스트 73개|
|배포 파일|플랫폼별 VSIX, Windows x64 기준 약 60MB|

{panel:title=04  권한과 보안|titleBGColor=#002f6d|titleColor=#ffffff|borderColor=#002f6d|borderStyle=solid|bgColor=#ffffff}
에이전트가 파일을 고치고 명령을 실행하는 도구라서, 무엇을 허용할지가 제일 중요했습니다.

*권한 모드 4가지* (입력창 하단에서 선택)
||모드||동작||
|Manual|파일 편집과 셸 명령 전에 매번 묻습니다.|
|Edit automatically|파일 편집은 묻지 않고 적용합니다.|
|Plan|읽기 전용입니다. 파일을 고치지 않습니다.|
|Auto|묻지 않고 모두 허용합니다.|

승인이 필요하면 입력창 위에 카드가 뜨고 Allow once, Always allow, Deny 중 하나를 고릅니다.

*엔진 접근 제한*
* 엔진은 {{127.0.0.1}}에서만 열리고, 포트는 실행할 때마다 새로 잡습니다.
* 실행마다 32바이트 무작위 비밀번호를 새로 만들어 Basic 인증을 겁니다. 같은 PC의 다른 프로세스가 포트를 알아내도 바로 붙을 수는 없습니다.
* 웹뷰에는 CSP를 적용해 nonce가 붙은 스크립트만 실행됩니다. 모델이 돌려준 마크다운은 DOMPurify로 정리한 뒤 그립니다.
* 모델 제공자 자격 증명은 확장이 저장하지 않습니다. {{opencode.json}}과 OpenCode 자체 저장소를 그대로 씁니다.

{panel:title=05  데모|titleBGColor=#002f6d|titleColor=#ffffff|borderColor=#002f6d|borderStyle=solid|bgColor=#ffffff}
# 폴더를 열고 {{Ctrl+Esc}}를 누릅니다. "Starting OpenCode…" 표시가 사라지면 준비된 것입니다.
# 함수 하나를 선택하고 우클릭해 *OpenCode: Add Selection to Chat* 을 누른 뒤 "이 함수가 하는 일 설명해 줘"라고 보냅니다.
# 입력창에 {{@}}를 치고 파일을 하나 첨부한 뒤 간단한 수정을 요청합니다. 권한 카드가 뜨면 Allow once를 누릅니다.
# 권한 모드를 Plan으로 바꾸고 같은 요청을 보냅니다. 이번에는 파일을 고치지 않고 계획만 내놓습니다.
# 왼쪽 History에서 앞서 나눈 대화를 다시 엽니다.

* Windows x64용 VSIX만 있습니다. 다른 OS에서는 엔진을 찾지 못해 동작하지 않습니다.

* 스킬 파일이나 {{opencode.json}}을 고치면 엔진을 다시 시작해야 반영됩니다.
