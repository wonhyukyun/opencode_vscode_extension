## 요약

OpenCode Integrated의 첫 공개 버전입니다. OpenCode 엔진을 VSIX에 내장해 CLI 설치나 터미널 없이 VS Code 사이드바에서 AI 코딩 에이전트를 사용할 수 있습니다.

## ✨ 신규 기능

- 내장 OpenCode 엔진(1.18.32)을 자동 기동·종료합니다. 루프백 주소와 무작위 비밀번호로만 접근합니다.
- 사이드바 채팅에서 스트리밍 응답, 도구 활동, 마크다운 렌더링을 제공합니다.
- 워크스페이스별 세션 목록에서 새 대화 생성·전환·삭제가 가능합니다.
- OpenCode 설정에 등록된 제공자·모델을 선택하고, 모델이 지원하면 사고 강도(effort)를 지정합니다.
- primary 에이전트가 등록된 경우 에이전트를 선택해 요청합니다.
- 편집기 선택 영역·현재 파일을 우클릭 메뉴 한 번으로 대화에 첨부합니다.
- `@`로 워크스페이스 파일을 검색해 첨부하고, `/`로 OpenCode 명령·스킬을 실행합니다.
- 이미지를 붙여넣기·드래그·버튼으로 첨부합니다.
- 도구 권한 요청을 패널에서 Allow once / Always allow / Deny로 응답합니다.
- 권한 모드 4종(Manual, Edit automatically, Plan, Auto)으로 기본 승인 정책을 정합니다.
- 에이전트의 선택형 질문에 패널에서 답합니다.
- 현재 컨텍스트·세션 누적 토큰과 컨텍스트 창 잔여량을 표시합니다.
- 단축키 `Ctrl+Esc`(사이드바 열기), `Ctrl+Shift+Esc`(새 채팅)를 제공합니다.

## ⚠️ 알려진 이슈 / 호환성 주의

- **Windows x64 전용 VSIX입니다.** 다른 OS·아키텍처에서는 설치 후 엔진을 찾지 못해 동작하지 않습니다.
- 모델 제공자 자격 증명 등록 UI가 없습니다. OpenCode CLI 또는 `opencode.json`으로 먼저 구성해야 합니다.
- 폴더를 열지 않은 상태에서는 엔진이 시작되지 않습니다.
- 폐쇄망·프록시 환경 검증 [확인필요]
