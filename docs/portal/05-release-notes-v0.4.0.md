## 요약

채팅 화면 구성을 바꾼 버전입니다. 채팅은 오른쪽 보조 사이드바로, 대화 기록은 왼쪽 History 뷰로 옮겼습니다. 저장소별 대화 기록, 여러 대화 일괄 삭제, Skills·MCP 서버 뷰를 새로 넣었습니다. 장시간 사용 시 확장 호스트가 메모리 부족으로 멈추던 문제도 고쳤습니다.

**VS Code 1.106 이상이 필요합니다.** 이전 버전(1.94 이상)을 쓰던 환경은 VS Code를 먼저 업데이트해야 합니다.

## ✨ 신규 기능

- **화면 배치 변경**: 채팅은 오른쪽 보조 사이드바의 **OpenCode Chat**에, 대화 기록은 왼쪽 **OpenCode > History** 뷰에 표시합니다. 채팅을 편집기 탭으로 열지 않습니다.
- **저장소별 대화 기록**: History 뷰에서 대화를 저장소 단위로 묶어 보여 줍니다. 현재 워크스페이스 저장소가 항상 맨 위에 오고, 하위 폴더에서 시작한 대화도 해당 저장소로 분류합니다.
- **대화 검색·더 보기**: 검색 버튼(**OpenCode: Search Chat History**)으로 제목·날짜·폴더를 검색합니다. **Load older chats...** 로 처음 50개 이후의 대화를 더 불러옵니다.
- **여러 대화 일괄 삭제**: **Select chats**로 여러 대화를 체크한 뒤 **Delete (N)** 로 한 번에 삭제합니다. 삭제에 실패한 대화는 선택된 채로 남아 다시 시도할 수 있습니다.
- **Skills 뷰**: 엔진이 불러온 스킬과 불러온 폴더를 보여 줍니다. 내장 스킬은 목록 아래쪽에 표시합니다.
- **MCP Servers 뷰**: 설정된 MCP 서버의 연결 상태를 보여 줍니다. 조치가 필요한 서버를 위쪽에 표시합니다.
- **에이전트별 모델 기억**: 에이전트마다 고른 모델과 사고 강도(effort)를 워크스페이스별로 저장하고, 해당 에이전트로 돌아오면 그대로 복원합니다.
- **편집기 제목 표시줄 버튼**: 파일을 연 편집기의 제목 표시줄 채팅 아이콘으로 History와 Chat을 함께 엽니다.
- **디버그 로그 출력**: 채팅 헤더의 버그 아이콘(**OpenCode: Dump Debug Log**)으로 최근 이벤트와 화면 상태를 출력 창에 기록합니다. 문제를 보고할 때 첨부합니다.

## 🔧 개선 사항

- **하위 에이전트 권한 요청 처리**: 하위 에이전트(task) 세션에서 올라온 권한 요청을 현재 대화로 연결해 표시합니다. Auto 모드에서는 이런 요청도 자동 승인합니다. 자동 승인이 실패하면 패널에 요청을 띄워 진행이 멈추지 않게 합니다.
- **질문 응답**: 에이전트 질문에 **Waiting for your answer** 상태를 표시합니다. 단일 선택 질문은 미리 선택된 답 없이 시작하고, **Skip without answering**으로 답하지 않고 넘길 수 있습니다.
- **질문 입력 보존**: 작성 중인 답은 새 이벤트가 오거나 대화를 전환해도 유지됩니다. 전송에 실패해도 질문과 답이 남아 다시 보낼 수 있습니다.
- **재연결 시 상태 복원**: 엔진과 다시 연결되면 대기 중인 질문, 권한 요청, 실행 상태를 다시 불러옵니다.
- **대화 기록의 질문 표시**: 지난 대화에서 질문과 답을 읽기 쉬운 형태로 표시합니다.
- **컨텍스트 창 표시**: 모델 변형(variant)이 따로 지정한 컨텍스트 크기를 반영하고, 응답이 스트리밍되는 동안의 토큰 수를 추정해 보여 줍니다.
- **기본 모델 설정**: `opencodeIntegrated.defaultModel`을 바꾸면 다시 시작하지 않아도 바로 적용됩니다. 에이전트에 아직 모델을 고르지 않았을 때 이 값을 미리 선택합니다.
- 엔진이 재시도(retry) 중일 때도 실행 중으로 표시합니다.

## 🐞 버그 수정

- **메모리 부족으로 멈추던 문제**: 긴 대화나 이미지가 많은 대화를 이어 가면 확장 호스트 메모리가 계속 늘어, `New chat` 같은 명령이 `RangeError: Out of memory`로 실패했습니다. 디버그용 이벤트 기록이 응답 전문, 도구 출력, 이미지 데이터를 그대로 쌓아 두던 것이 원인이었습니다. 이제 긴 값은 잘라서 기록합니다.
- **모델 선택이 전달되지 않던 문제**: 화면에는 고른 모델이 보이는데 실제 요청에는 모델이 빠지던 문제를 고쳤습니다. 이전 버전에서 저장한 모델 선택도 그대로 읽습니다.

## ⚠️ 알려진 이슈 / 호환성 주의

- **VS Code 1.106 이상이 필요합니다.** 보조 사이드바 기능 때문이며, 하위 버전에는 설치되지 않습니다.
- **Windows x64 전용 VSIX입니다.** 다른 OS·아키텍처에서는 엔진을 찾지 못해 동작하지 않습니다.
- 이전 버전에서 채팅 뷰 위치를 직접 옮겼다면, 업데이트 후 VS Code가 기억한 배치가 그대로 유지될 수 있습니다.
- 대화를 열면 최근 메시지 200개까지만 불러옵니다.
- 하위 에이전트가 쓰는 모델은 이 확장에서 바꿀 수 없습니다. OpenCode 에이전트 설정에서 지정해야 합니다.
- 모델 제공자 자격 증명 등록 UI가 없습니다. OpenCode CLI 또는 `opencode.json`으로 먼저 구성해야 합니다.
- 폴더를 열지 않은 상태에서는 엔진이 시작되지 않습니다.
- 폐쇄망·프록시 환경 검증 [확인필요]
